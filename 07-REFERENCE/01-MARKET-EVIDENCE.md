# 01-MARKET-EVIDENCE — The verified market case and the fact-check gate for all marketing copy

**Why this file exists / when to use it:** AppealDeck sells into a market that was burned by liars — bribery prosecutions, fake success rates, "guaranteed reinstatement" scams. Our credibility is the product, so every number we publish must be true and traceable. This file is the single source of truth for market claims: **no marketing claim ships — landing page, store listing, community post, ad, email — unless it maps to a row in the verified table below (§1) or is added here with a source first.** It also carries the full banned-numbers list (§4): figures invented by earlier AI research that must never appear anywhere, in planning or in public.

**Terms used below:** POA = Plan of Action, the structured appeal document Amazon requires. ASIN = Amazon Standard Identification Number (one product listing). AHR = Account Health Rating, Amazon's 0–1000 account score. AHA = Account Health Assurance, Amazon's free protection program for high-AHR Professional sellers. Amelia = Amazon's AI assistant inside Seller Central. CWS = Chrome Web Store. Section 3 = the clause of Amazon's Business Solutions Agreement used for fraud/deceptive-activity deactivations. SERP = search-engine results page.

All verifications below were performed 25 Aug 2026 by this playbook's authors against live web sources [source: VERIFICATIONS.md]; they override any conflicting figure in older research documents.

## 2. How the fact-check gate works

The rule: **no marketing claim ships unless it appears in §1's verified tables.** Enforcement:

- [ ] **1. Run the claim gate on every marketing artifact before it ships** — landing page, CWS listing, community post, ad, email. Each factual claim must map to a §1 row; each number must carry its verification date; grep for "guarantee" must return 0 hits (decision D6); no success-rate statement of any kind until our own opt-in outcome data exists; no "first", "only", or "zero competition" claims (refuted — see `02-COMPETITOR-DOSSIER.md`); no insider framing. **Owner:** AI assistant (check) + Founder (sign-off) · **Cost:** $0 · **Deadline:** every artifact, continuous · **Blocks:** every public word.
- [ ] **2. New claims enter this file before they enter copy.** Verify against a primary source, add the row with source and date, then use it. **Owner:** AI assistant · **Cost:** $0 · **Deadline:** continuous · **Blocks:** claim-gate integrity.
- [ ] **3. Re-verify the §1.2 price anchors before each major marketing push and at least quarterly** — competitor prices drift, and a stale anchor is a false claim. **Owner:** Founder · **Cost:** $0 (1h) · **Deadline:** quarterly from launch · **Blocks:** anchor-based copy.
- [ ] **4. Build the opt-in outcome pipeline before any win-rate statement is even drafted** (funnel stage 5 of decision D10). Until it reports, the answer to "what's your success rate?" is: "We publish outcomes only from opted-in users, and we don't have enough data yet — most first appeals fail industry-wide, even with expensive help." **Owner:** AI assistant (build) + Founder (policy) · **Cost:** included · **Deadline:** before any outcome claim · **Blocks:** all win-rate copy, forever.

## 4. The banned-numbers list

| Banned figure/claim | Why it is banned |
|---|---|
| Win rates "30–40%", "40–60%", "65–80%" | Invented — no such data exists anywhere; only unverifiable consultant marketing claims exist. |
| "AI 72% vs human 94%" win-rate comparison | Invented — no study, no source, pure fabrication. |
| "87% across 42 appeals" | Invented — fabricated track record; we have zero appeals of our own yet. |
| "$2.3M ARR" projection | Invented — no acquisition model behind it; only the conservative case (~$17k gross year 1) is planning-grade. |

| "2M+ active sellers" | Stale — Marketplace Pulse tracks ~1.65M active and shrinking; 165k new sellers in 2025 was a decade low. |
| "5% adoption = 100k users" | Invented adoption rate multiplied by a stale base — double fiction. |
| "17 days to submit POA" | A 2017–19 notice artifact; current notices state their own window (commonly 90d, some 60d) — parse the stated window, never assume a constant. (Kept only as a legacy parse pattern in the deadline engine.) |

| "Funds withdrawable after 90 days" | Wrong — 90d is a default hold checkpoint, never automatic; since Oct 2024 funds are APPEAL-eligible at +60d (disbursement appeals); fraud-class holds are indefinite. |

| "$15/user/mo expert cost" | Invented — credible bench rates are ~$75–150/case (judgment from live freelance rates); this figure made a bundled-expert subscription look viable when it is not. |
| "4 big appeal extensions removed 2024–25" | Never existed — zero evidence any such extensions ever existed, let alone were removed. |
| "Amazon TOS says only the account owner can submit a POA" | Fabricated clause — no such term exists; VAs and agencies submit routinely. The real no-automation basis is BSA §19 + Seller Code of Conduct. |
| "Think3" / "Amazing Sellers" agencies | Likely invented — no trace of either firm; real firms are named in §1.2. |
| "2–3 weeks WhatsApp approval" | Invented and irrelevant — WhatsApp Business approval runs 24–48h via a BSP; v1 uses no WhatsApp at all. |
