# 08-SOURCE-DOCUMENT-INDEX — The archaeology index of every research document behind this playbook

**Why this file exists / when to use it:** this playbook was distilled from 34 files in `V:\Extension 2.3\Future\` — five AI research rounds, their duplicates, transcripts, tasking prompts, and ten resource streams. Several of those files confidently state things that are now known to be wrong, superseded, or outright invented. This index exists so nobody ever mistakes a superseded document for current truth: look up any source file here BEFORE citing it, and you will see what it is, how much to trust it, whether something replaced it, and which playbook file already absorbed its usable content. If you are about to quote a source document directly, stop — quote the absorbing playbook file instead.

**Terms used below:** POA = Plan of Action (Amazon's required appeal document). MoR = Merchant of Record. CWS = Chrome Web Store. BSA §19 = Amazon's March-2026 Agent Policy. UPL = unauthorized practice of law. "Kilo" = the AI research-manager persona that authored Rounds 4–5 and the stream reports. "Round" numbering follows the chronology in `../00-DECISION/02-DECISION-LOG.md` §1.

## 1. How to read this index

**Precedence when sources conflict (memorize this):** the Synthesis Brief and this playbook override everything → **`The Second Opinion.md` is authoritative over all documents before it** → newer documents beat older ones → `Ai-chat.txt` is banned as a source of numbers entirely. The playbook's own 25 Aug 2026 web verification (`01-MARKET-EVIDENCE.md`) overrides any conflicting research-round claim.

**Reliability grades:**
| Grade | Meaning |
|---|---|
| **A** | Grounded — key claims independently re-verified live by the playbook's authors |
| **B** | Mixed, leaning grounded — major vendor/legal facts check out; some citations decorative; use with spot-checks |
| **C** | Mixed — real backbone but significant invented citations, circular sourcing, or self-attested "verification"; use directionally, verify every number before money/copy |
| **D** | Unverified — tasking prompts, transcripts, or ideation whose substance was never checked; use for provenance/context only |
| **F** | Banned-numbers — every specific figure is presumed invented or stale; listed in the banned-numbers register (`01-MARKET-EVIDENCE.md` §4) |

**Statuses:** `canonical` (still the best source for its lane, caveats noted) · `superseded-by-X` (do not execute; X wins) · `duplicate-of-X` (same content, different container) · `ideation-only` · `research-brief` (a prompt, not findings) · `banned-numbers`.

1. **Stream numbers are unreliable.** Two files are labeled Stream 9 (payments/tax AND distribution), two are Stream 10 (PMF edge cases AND talent), two are Stream 7 (partnership risk AND security), the crisis file says Stream 8 despite its filename, and the channel-mechanics file says Stream 4. **Always cite streams by filename, never by number.**

3. **"Verified live Aug 2026" inside a stream file is self-attestation, not verification.** Multiple streams carry that footer above tables containing invented citation domains. Only `01-MARKET-EVIDENCE.md` and the (verified) tags in this playbook count as verification.
4. **The banned-numbers register applies to every file here.** Even canonical files repeat banned figures when quoting the chat or early rounds — the register (`01-MARKET-EVIDENCE.md` §4 and the Synthesis Brief) always wins.
5. **The build plan is read through its amendments.** Anyone opening `APPEALDECK_BUILD_PLAN.md` (or its .html twin) must read `../03-PHASE-2-BUILD/02-BUILD-PLAN-AMENDMENTS.md` first — the payments architecture and the build order in the original are superseded.
