# Recruitment log template (CSV / sheet)

Columns (one row per candidate):
```
date, channel, candidate_handle, gig_order_id, trap1_deadline_pass, trap2_invoice_pass, structure_pass, tone_pass, overall_verdict, notes
```

Example row:
```
2026-09-10, Upwork, seller_pro_01, 48213, yes, yes, yes, yes, HIRE, strong root-cause mapping
2026-09-10, Fiverr, poa_quick, 99102, no, no, yes, no, FAIL, invented 17-day deadline + fabricated invoice
```

Verdict rule: overall = HIRE only if all four = yes. Track spend per channel for the ~$500–1,200 program budget.
