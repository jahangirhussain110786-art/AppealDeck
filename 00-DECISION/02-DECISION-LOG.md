# 02-DECISION-LOG — The full decision trail

**Why this file exists / when to use it:** Six research rounds and one independent verification pass produced the current plan. This file records how each decision was reached, which decisions were overturned along the way, and why — so nobody re-litigates a settled question or, worse, quietly executes a superseded one. Consult it whenever a source document seems to contradict the playbook: the chronology below explains which document wins. New decisions and exceptions are appended here with a date.

**Precedence rule for conflicting sources:** the Synthesis Brief and this playbook override all older documents → `The Second Opinion.md` overrides everything before it → newer documents override older ones. The Ai-chat transcript is banned as a source of numbers entirely.
