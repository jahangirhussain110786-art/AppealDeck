## In the product
The header, footer and auth card render the mark as an inline React SVG (`src/components/Logo.tsx`, spec §1.3) so it needs no request, and the wordmark is live text ("Appeal" + "Deck" in one `<span>`, so no gap). The component uses the `--brand` token for the square and the check and `fill-white` for the sheets; it is identical to `mark.svg` at every size.

## Usage rules
- Minimum sizes: mark 16 px; horizontal logo 120 px wide; below that use the mark alone.
- Clear space around the mark = its corner radius (¼ of its width). Do not crop the sheets.
- Never recolour the mark, never place it on a green or mint background, never add shadows or gradients to it.
- Wordmark is Inter SemiBold with −0.02 em tracking, "Deck" in green (light) or mint (dark); never letter-space it further, never set it in another face.
- Social avatars: `icon-512.png` (square, opaque). Circular crops: `icon-512-maskable.png`.
- Email signature: `logo-horizontal-light@2x.png` at 172 × 32 CSS px.

## Regenerating
`docs/handoffs/assets/brand-gen.js` — a Node script that needs `opentype.js@1.3.4` and an Inter SemiBold font file next to it (Google Fonts serves a WOFF that opentype.js reads) and uses the repo's own Playwright Chromium to rasterise. It writes every file above deterministically; edit the geometry constants at the top, run once, commit the outputs.
