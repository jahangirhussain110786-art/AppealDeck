# AppealDeck — current state

**What a seller can actually do today, where, and what it still depends on.** Checked against the
code on 24 Sep 2026 at the commit that added this file. Updated the same day for wording help, saved document checks, seller-entered dates, the change-of-approach panel and the extension decision. This is the register to read first; the
handoffs in `docs/handoffs/` and the status bullets in `CLAUDE.md` are history.

**The rule for this file (from the 23 Sep ChatGPT audit, §10):** a capability is listed as
**Live** only if a seller can reach it from the running app, it survives save, reload and
sign-in, and a test proves it. Code that exists but no seller can reach is **not** live. When a
capability changes, change its row in the same commit.

Status: **Live** — reachable and tested · **Needs config** — built and tested, but does nothing in
production until a founder step is done · **Not built** — deliberately absent, with the reason.

## Not built, on purpose

| What                                                            | Why                                                                                                                                                                                                                                                                                                    | Decided                             |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------- |
| AI drafting of whole responses                                  | Deliberately not built. Since 24 Sep 2026 the only AI writing help is opt-in wording help per section, with the facts locked in code (`wordingLock.ts`). The old whole-section AI rewrite in `/api/compose` (AM-23) was removed the same day, so preparing a response sends nothing to an AI provider. | 24 Sep 2026, founder                |
| Browser extension                                               | Dropped from the plan. Paste-only, it would be the web page in a popup; reading Seller Central or writing into it breaches Amazon's Agent Policy, which binds the seller.                                                                                                                              | AM-27 (22 Sep), AM-28 (24 Sep 2026) |
| Guardian subscription, Expert Review, a Guardian waitlist       | Deferred until monitoring exists and payment rails allow it. No waitlist: it would promise something that may never ship.                                                                                                                                                                              | D7; 24 Sep 2026                     |
| Marketplaces other than Amazon US; languages other than English | Scope.                                                                                                                                                                                                                                                                                                 | D7                                  |
| Win rates or approval odds                                      | Only from opt-in outcome data with a denominator, and there is none yet.                                                                                                                                                                                                                               | D6                                  |

## Engineering baseline

Next.js 16.3.6 · React 19 · Node 24 · TypeScript (tests typechecked too) · Vitest · Playwright ·
ESLint 9. Gates, all run by CI on every push: `npm run typecheck`, `lint`, `lint:copy`,
`lint:reachability`, `lint:sources`, `format:check`, `build`, `test`, the Playwright chromium
suite, and Lighthouse (accessibility, best practices and SEO are hard failures). Run the browser
suite as CI does: build first, then `CI=1 npx playwright test --project=chromium --retries=0`.
