# v5 prototype vs the real app: what still differs (26 Sep 2026)

AM-31 (`2791358`) gave the whole app the v5 look: tokens, fonts, navy bands, pill buttons, sidebar, page headers. It did **not** rebuild each page's body to match the prototype. The founder asked whether the app now looks exactly like v5; the honest answer is no. This list comes from full-page screenshots of every prototype page next to the matching app page at 1440 px (light).

Prototype: `docs/handoffs/2026-09-26-prototype-v5/` (preview: launch.json `prototype-v5`, port 4402).

## Deliberate differences (keep)

- The logo and the announcement bar (founder).
- Full legal privacy text; EU withdrawal consent order on pricing.
- e2e-asserted labels (see the e2e specs) and the legal name in the operator paragraph.
- Prototype sample data (cases, files, timeline) is fiction; real pages render the seller's own data in the same design.

## Suggested order

Case → dashboard → decode result → pricing → support → home → privacy → vault. After each page, re-screenshot against the prototype and run the gates (typecheck, lint, lint:copy, lint:reachability, vitest, build, then `CI=1 npx playwright test --project=chromium --retries=0`).
