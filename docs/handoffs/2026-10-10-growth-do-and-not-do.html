7How to build it safely

  • Order: batch A, then B, then C. One batch per commit, gates once per batch (typecheck, lint, lint:copy, lint:reachability, lint:sources, format, vitest, build, Playwright CI=1 --retries=0).
  • Rule on every word: no "guarantee", no win rate, no prediction of Amazon's decision, nothing read from Seller Central (D6, AM-27).
  • Two features need their own e2e test, because they lose all value silently if unwired: the one-tap sample (G-77) and the reply reader door (G-01).
  • The renamed button (G-88) changes six e2e specs in the same commit.
  • Do not start on a general "go ahead". Name the batch, for example "do batch A", or name IDs.
