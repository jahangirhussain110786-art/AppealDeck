# Test documents for uploading (29 Sep 2026)

Fake documents for testing the case's Documents tab. Every business, person, bank, lab and address in them is invented; phone numbers use 555 and email addresses end in `.example`. Every file is stamped **TEST DOCUMENT — NOT VALID**. Never send one to Amazon or anyone else.

## How to use them

1. Start a case with a notice:
   - **The app's own sample:** Decode → "Try a sample notice" → Decode → "Open case workspace".
   - **One of the researched notices:** open the matching `paste-notice-….txt` in this folder, copy all of it, and paste it into the case's notice box.
2. Press "Yes, this is right", then open the **Documents** tab.
3. Open the document's card and press **Choose a file**.
4. Optional, for invoices: under "Your business details", enter the invented seller below, so a document check compares against it.

**Invented seller:**

- Business name: `Brightwater Home Goods LLC`
- Address: `214 Juniper Lane, Suite 5, Austin, TX 78701, United States`
- Suppliers: `Harbor Goods Wholesale Ltd`, `Crestline Trade Supply Co.`

## What "Check this document" can do today

- **Identity and proof-of-address pictures** are checked on your own device, signed in or not. They are never read.
- **Invoices, letters, reports and statements** get the **AI reading** when it can run: you are signed in, the case has an Appeal Pass, the file is up to 3 MB, and the AI is switched on for the site. The file goes to AppealDeck and on to Google Gemini.
- **When the AI reading cannot run, or for a guest, the same documents are read on your own device, without AI** (30 Sep 2026): the words of a PDF are read by pdf.js, a scan or a photo (PDF, PNG, JPEG or WebP, up to 10 MB) by Tesseract.js OCR. The result says "Read on this device, without AI" and why the AI reading was not used. It finds labels and patterns (dates, ASINs, phone numbers, standards such as UL 62368-1); it does not understand the document, so it says "Not checked" where the AI reading would have answered, and a word that only sits near an answer is quoted as a pointer, never shown as "Found". The same comparisons are made against today's date, the notice's ASINs and your business details.
- **Whether the file left the device depends on who pressed the button.** A guest's file is never uploaded. A signed-in seller's file is posted to AppealDeck first (the AI reading is tried first), so if that reading cannot run, the result says the file was sent to AppealDeck for the AI reading and was then read on the device. A file over 3 MB is never sent.
- **Where the AI is on:** on appealdeck.vercel.app neither the Gemini key nor `GEMINI_PAID_TIER_CONFIRMED` is set (checked 29 Sep), so every business-document check there is a device reading. On your computer `.env.local` has both (checked 30 Sep), so a signed-in check with a Pass tries the AI first, on the free tier's 20 requests a day, and falls back to the device reading when Google refuses. To test the fallback deliberately, start the server with `GEMINI_PAID_TIER_CONFIRMED=false`, as `e2e/device-reader.spec.ts` expects. Real use waits on the Gemini billing step (DEPLOYMENT §6b).
- Saving and linking every file works everywhere.

## Making them again

```
node docs/handoffs/2026-09-29-test-documents/generate.cjs
```

It needs the project's installed Playwright, and remakes every file in this folder except this guide and `16-wrong-file-type.txt`. Two files also need Python: `18` needs Pillow with JPEG 2000 support (`make-jpx-scan.py`) and `19` needs only the standard library (`make-protected-pdf.py`); the generator says "SKIPPED" for either if Python is missing. Regenerating rewrites the other PDFs with new timestamps, so `git checkout` the ones you did not mean to change.
